# Project skills

Project-specific skills go here, one folder per skill with a `SKILL.md`
(format: https://agentskills.io/specification). OpenCode, Claude Code and Codex load them
automatically. Shared, general-purpose skills are installed globally from the AI Reference
repository (`~/.agents/skills/`); do not copy those here.

Delete this README when you add the first skill, or keep it as a pointer.
